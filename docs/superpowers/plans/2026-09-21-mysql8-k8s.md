# MySQL 8 K8s（Docker Desktop）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将本地 Docker `mysql8` 迁到 Docker Desktop Kubernetes，并保持 Compose 业务可连。

**Architecture:** StatefulSet + hostpath PVC + LoadBalancer Service；Secret 由脚本生成；数据经 mysqldump 一次性导入。

**Tech Stack:** Kubernetes 1.x（docker-desktop）、mysql:8.0、bash/kubectl

## Global Constraints

- 命名空间 `mdyaipay-infra`；Service 名 `mysql8`。
- 密码环境变量 `MDYAIPAY_MYSQL_ROOT_PASSWORD`，默认 `123456`。
- StorageClass `hostpath`；容器内存 2Gi。
- 设计文档：`docs/superpowers/specs/2026-09-21-mysql8-k8s-design.md`
